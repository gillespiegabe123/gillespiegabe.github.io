# Gabriel Gillespie Portfolio

Static personal portfolio website for economics, data analysis, policy research, research analyst, and business analyst applications.

## Files

- `index.html` - page content and sections
- `styles.css` - layout, colors, and responsive design
- `script.js` - mobile navigation and current year

## Personalize Before Publishing

Update these placeholders in `index.html`:

- Resume link: replace `href="#"` with your resume PDF path
- Writing sample link: replace `href="#"` with your writing sample PDF path
- GitHub link: replace `href="#"` with your GitHub profile URL
- Project titles and descriptions
- Skills, tools, and project bullets

Suggested file names:

```text
resume.pdf
inequality-homelessness.pdf
ubi-public-finance.pdf
airbnb-price-prediction.pdf
namibia-case-study.pdf
```

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, and any PDF files to your GitHub repository.
2. In the repository, go to `Settings` > `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select the `main` branch and `/root`.
5. Click `Save`.

GitHub will publish the site after a short wait.
