# Student Project Portfolio

This is a static portfolio website designed for GitHub Pages. Edit the placeholder name, contact links, project titles, and project descriptions before publishing.

## What to Change

- `index.html`: Replace `Your Name`, email, GitHub, LinkedIn, project names, project descriptions, and project links.
- `assets/images/hero-workspace.png`: Replace with your own workspace photo or project screenshot if you want.
- `assets/styles.css`: Adjust colors or spacing.

## Publish on GitHub Pages

1. Create a new GitHub repository named `yourusername.github.io` for a personal site, or any repository name for a project site.
2. Upload everything inside this `portfolio-site` folder to the repository.
3. In GitHub, open `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/root`, then save.
6. GitHub will publish the site after a short build.

For a personal site, the URL will usually be:

```text
https://yourusername.github.io
```

For a project site, the URL will usually be:

```text
https://yourusername.github.io/repository-name
```
